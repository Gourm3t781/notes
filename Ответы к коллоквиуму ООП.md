## Вопрос № 1. «Типы данных, объявление переменных и констант»

**Ответ.**

### Типы данных

В Java предусмотрено **8 примитивных типов данных**. Все остальные типы являются **объектными**.

| Тип       | Размер  | Диапазон значений            |
|-----------|---------|------------------------------|
| `byte`    | 1 байт  | −128 … 127                   |
| `short`   | 2 байта | −32768 … 32767               |
| `int`     | 4 байта | −2³¹ … 2³¹ − 1           |
| `long`    | 8 байт  | −2⁶³ … 2⁶³ − 1           |
| `float`   | 4 байта | вещественное число           |
| `double`  | 8 байт  | вещественное число           |
| `char`    | 2 байта | символ                       |
| `boolean` | —       | `true` / `false`             |

### Объявление переменных

Общая форма объявления переменной:

```
<тип> <имя_переменной>;
```

Переменную можно объявить без значения, сразу с начальным значением, а также объявить несколько переменных одного типа через запятую:

```java
int x;
double y;
char c;
int a, b;              // несколько переменных одного типа
int percent = 10;      // объявление с инициализацией
int m = 5, n = 10;     // несколько переменных с инициализацией
```

### Константы

Константа объявляется с модификатором `final`: такую переменную после присваивания значения изменить нельзя. В Java константы принято именовать **заглавными буквами**.

```java
final int MAX_SIZE = 100;
final double PI = 3.14;
```

## Вопрос № 2. «Ввод/вывод»

**Ответ.**

### Вывод

Для ввода/вывода используется встроенный класс `System`. Для вывода используется его объект `out` с методами:

- `print()` — выводит значение без перевода строки;
- `println()` — выводит значение и переводит курсор на новую строку.

```java
System.out.print("Hello, world");
System.out.println("Hello, world");

int a = 10;
// a = 10 (склейка строки и числа через +)
System.out.println("a = " + a);
```

### Ввод

Для ввода используется класс `Scanner`. Необходимо создать объект этого класса и связать его со стандартным входным потоком `System.in`. Основные методы:

- `nextInt()` — считывает целое число;
- `nextDouble()` — считывает вещественное число;
- `next()` — считывает одно слово;
- `nextLine()` — считывает всю строку.

```java
import java.util.Scanner;

class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);

        System.out.println("Введите целое число:");
        int a = sc.nextInt();

        System.out.println("Введите вещественное число:");
        double d = sc.nextDouble();

        System.out.println("Введите слово:");
        String s = sc.next();

        System.out.println("a = " + a + ", d = " + d + ", s = " + s);
    }
}
```

## Вопрос № 3. «Класс String»

**Ответ.**

`String` — объектный (не примитивный) тип для работы со строками. Строку можно создать, просто присвоив переменной строковый литерал. Основные методы класса:

| Метод | Описание |
|-------|----------|
| `length()` | Возвращает текущую длину строки. |
| `charAt(int index)` | Возвращает символ на заданной позиции. |
| `compareTo(String s1)` | Сравнивает строки на больше/меньше: отрицательное число (например, −1), если параметр больше исходной строки; положительное (например, 1), если меньше; `0`, если строки равны. |
| `equals(String s1)` | Сравнивает строки на равенство, возвращает `true` / `false`. |
| `equalsIgnoreCase(String s1)` | Сравнивает строки на равенство без учёта регистра. |
| `indexOf(String s1)` | Возвращает позицию первого вхождения подстроки `s1`. |
| `lastIndexOf(String s1)` | Возвращает позицию последнего вхождения подстроки `s1`. |
| `startsWith(String s1)` / `endsWith(String s1)` | Проверяет, начинается / заканчивается ли строка заданной подстрокой. |
| `substring(int p1, int p2)` | Извлекает подстроку, начиная с позиции `p1` и до позиции `p2` (символ на позиции `p2` не включается). |

Пример использования:

```java
String s = "Java";

System.out.println(s.length());                  // 4
System.out.println(s.charAt(0));                 // J
// false (регистр различается)
System.out.println(s.equals("java"));
System.out.println(s.equalsIgnoreCase("java"));  // true
System.out.println(s.indexOf("a"));              // 1
System.out.println(s.lastIndexOf("a"));          // 3
System.out.println(s.startsWith("Ja"));          // true
System.out.println(s.substring(1, 3));           // av
```

## Вопрос № 4. «Массивы в Java»

**Ответ.**

В Java все массивы являются **динамическими**, поэтому прежде чем начать работу с ними, необходимо выделить память с помощью вызова `new`.

### Одномерные массивы

Структура объявления массива:

```
<тип_элемента>[] <имя_массива>;
<тип_элемента>[] <имя_массива> = new <тип_элемента>[<размер>];
```

С каждым массивом связано свойство `length`, которое позволяет обращаться к текущей длине массива. Также имеется возможность одновременного объявления и инициализации массива.

```java
int[] a;                         // только объявление
a = new int[100];                // выделение памяти
int[] c = new int[100];          // объявление и выделение памяти сразу

for (int i = 0; i < a.length; i++)
    a[i] = i;

int[] b = {1, 2, 3, 4, 5};       // объявление с инициализацией
```

### Двумерные массивы

```
<тип_элемента>[][] <имя_массива>;
<тип_элемента>[][] <имя_массива> =
        new <тип_элемента>[<размер1>][<размер2>];
```

```java
int[][] a = new int[100][50];

for (int i = 0; i < a.length; i++)           // a.length — число строк
    // a[i].length — длина строки i
    for (int j = 0; j < a[i].length; j++)
        a[i][j] = i + j;

int[][] b = {{1, 2, 3}, {4, 5, 6}};
```

### Массив объектов

Элементами массива могут быть и объекты. Например, в массив типа родительского класса можно поместить объекты разных классов-наследников (см. вопрос 8):

```java
Figure[] f = new Figure[n];
f[0] = new Circle(a);
f[1] = new Triangle(b);
```

## Вопрос № 5. «Классы и основные понятия»

**Ответ.**

### Класс

**Класс** — это базовый элемент объектно-ориентированного программирования. Класс представляет собой **шаблон**, по которому в программе будут строиться различные объекты. Класс определяет структуру объекта (поля) и его методы, которые образуют функциональный интерфейс. В Java классы принято именовать с большой буквы.

Структура класса:

```
[<модификатор доступа>] class <имя класса> [extends <имя суперкласса>]
{
    [<модификатор>] <тип> <поле 1>;
    ...
    [<модификатор>] <тип> <поле N>;

    [<модификатор>] <тип результата> <имя метода 1>(<список параметров>)
    {
        // тело метода 1
    }
    ...
    [<модификатор>] <тип результата> <имя метода M>(<список параметров>)
    {
        // тело метода M
    }
}
```

Объявление полей схоже с объявлением переменных. В качестве типа поля может быть использован любой примитивный или объектный тип.

### Инкапсуляция

Первый принцип ООП называется **инкапсуляцией**: содержимое класса скрыто от внешнего мира, и вне класса доступно только использование его методов. Прямой доступ к полям объекта извне нарушает инкапсуляцию — работать с полями следует через методы класса.

### Основные понятия

- **`this`** — ссылка на текущий объект. Позволяет обращаться к собственным элементам класса, например, различать поле и параметр метода с одинаковым именем.
- **Конструктор** — специальный метод, который служит для инициализации полей объекта после его создания. Имя конструктора всегда совпадает с именем класса, и он не имеет типа возвращаемого результата.
- **Совмещение методов (перегрузка)** — возможность создавать несколько методов с одинаковым именем, но разным списком параметров. Применяется и для конструкторов, и для обычных методов. Какую версию вызвать, решается по списку фактических параметров.
- **Экземпляр класса** — конкретный представитель класса с конкретным набором данных. Для создания экземпляра используется вызов `new` с указанием нужного конструктора.

```java
class Point
{
    int x, y;

    Point(int x, int y)          // конструктор с параметрами
    {
        this.x = x;              // this.x — поле, x — параметр
        this.y = y;
    }

    Point()                      // совмещённый конструктор без параметров
    {
        x = -1;
        y = -1;
    }

    int getX() { return x; }
    int getY() { return y; }

    double dist(int x, int y)    // расстояние до точки (x, y)
    {
        int dx = this.x - x;
        int dy = this.y - y;
        return Math.sqrt(dx * dx + dy * dy);
    }

    // совмещённый метод: расстояние до точки p
    double dist(Point p)
    {
        return dist(p.getX(), p.getY());
    }
}

class Main
{
    public static void main(String[] args)
    {
        Point p1 = new Point(10, 20);
        System.out.println("x = " + p1.getX() + " y = " + p1.getY());

        Point p2 = new Point(30, 30);
        double d = p1.dist(p2);      // вызов версии dist(Point)
        System.out.println(d);

        double r = p1.dist(0, 0);    // вызов версии dist(int, int)
        System.out.println(r);
    }
}
```

В примере создаются два экземпляра класса `Point`, никак не связанные между собой. Метод `dist` является совмещённым: какую его версию вызвать, решается исходя из списка фактических параметров.

## Вопрос № 6. «Классы, наследование, полиморфизм»

**Ответ.**

Три базовых принципа ООП: **инкапсуляция** (см. вопрос 5), **наследование** и **полиморфизм**.

### Наследование

**Наследование** позволяет строить иерархии классов, в которых классы-потомки обладают всеми полями и методами родительских классов и расширяют их своими полями и методами.

- Классы-потомки называют **подклассами**, непосредственного предка — **суперклассом**.
- Наследование задаётся ключевым словом **`extends`**, после которого указывается имя суперкласса.
- В Java разрешено только **одиночное наследование**: у каждого класса может быть только один суперкласс.
- Ключевое слово **`super`** позволяет обратиться к конструктору суперкласса (`super(...)`) или к его методу (`super.метод()`).
- Ключевое слово **`this(...)`** в конструкторе позволяет вызвать другой конструктор этого же класса.

Например, класс «трёхмерная точка» `Point3D` во многом повторяет код класса `Point`. Чтобы не дублировать код, его наследуют от `Point`: поля `x`, `y` и методы `getX()`, `getY()` неявно присоединяются к `Point3D`.

```java
class Point3D extends Point
{
    // x, y, getX(), getY() унаследованы от Point
    int z;

    Point3D(int x, int y, int z)
    {
        super(x, y);             // вызов конструктора суперкласса
        this.z = z;
    }

    Point3D()
    {
        super();                 // x = -1, y = -1
        z = -1;
    }

    int getZ() { return z; }
}
```

Конструктор без параметров можно записать и через вызов другого конструктора этого же класса:

```java
Point3D()
{
    this(-1, -1, -1);        // вызов конструктора Point3D(int, int, int)
}
```

### Замещение методов

Если в родительском классе и в наследнике объявлен метод с **одинаковым именем и списком параметров**, то метод наследника перекрывает родительский. Такая техника называется **замещением методов** (переопределением).

```java
public class Person
{
    private String name;
    private String surname;

    public Person(String name, String surname)
    {
        this.name = name;
        this.surname = surname;
    }

    public void displayInfo()
    {
        System.out.println("Имя: " + name + " Фамилия: " + surname);
    }
}

class Employee extends Person
{
    private String company;

    public Employee(String name, String surname, String company)
    {
        super(name, surname);
        this.company = company;
    }

    public void displayInfo()       // замещает метод Person
    {
        super.displayInfo();        // вызов родительской версии
        System.out.println("Компания: " + company);
    }
}
```

### Полиморфизм

**Полиморфизм** — возможность использовать методы с одинаковым названием для различных объектов одной иерархии наследования, при этом объекты реагируют на них по-разному.

Простейшее проявление полиморфизма — возможность присвоить переменной родительского класса экземпляр дочернего класса.

```java
class A
{
    void method() { System.out.println("Inside A method"); }
}

class B extends A
{
    void method() { System.out.println("Inside B method"); }
}

class Main
{
    public static void main(String[] args)
    {
        A a = new B();
        a.method();        // Inside B method
    }
}
```

Это механизм **динамического назначения методов**: во время компиляции проверяется наличие метода в классе `A`, а во время выполнения Java-машина видит, что в переменной `a` фактически находится экземпляр класса `B`, и вызывает версию метода из класса `B`.

## Вопрос № 7. «Модификаторы доступа»

**Ответ.**

**Модификаторы доступа** — ключевые слова, которые позволяют задать уровень доступности классов, полей и методов.

| Модификатор | Область доступности |
|-------------|---------------------|
| `public` | Общедоступный элемент, виден из любой точки программы. |
| `protected` | В рамках иерархии наследования и в пределах пакета. |
| *по умолчанию* (default) | Если модификатор не указан. Доступ в пределах пакета. |
| `private` | Только в пределах самого класса. |

```java
public class Person
{
    private String name;            // доступно только внутри Person
    protected int age;              // доступно наследникам и в пакете
    // доступ по умолчанию — в пределах пакета
    String city;

    public String getName()         // доступно отовсюду
    {
        return name;
    }
}
```

### Прочие модификаторы

- **`final`** — обозначает невозможность модификации.
  - переменная `final` — константа;
  - метод `final` нельзя переопределить в наследнике;
  - от класса `final` нельзя наследовать.
- **`static`** — элемент привязан к самому классу, а не к экземпляру.
  - поле `static` существует в единственном числе для всех экземпляров класса;
  - метод `static` можно вызывать без привязки к конкретному экземпляру.
- **`sealed`** — появился в новых версиях языка; позволяет ограничить наследование явным указанием возможных наследников (после `permits`).

```java
public sealed class Shape permits Circle, Square
{
    // общая логика для всех фигур
}

public final class Circle extends Shape { /* логика для круга */ }

public final class Square extends Shape { /* логика для квадрата */ }
```

## Вопрос № 8. «Абстрактные классы»

**Ответ.**

Иногда нужно определить класс, в котором задана структура некоторой абстракции, но полная реализация всех методов отсутствует.

- Метод без реализации называется **абстрактным методом** (`abstract`).
- Класс, в котором есть абстрактные методы, тоже должен быть помечен как **абстрактный** (`abstract class`).
- Наследники абстрактного класса должны предоставить реализацию абстрактных методов. Если наследник этого не делает, он сам должен быть объявлен абстрактным.
- Так как полной реализации нет, **нельзя создавать объекты абстрактного класса** через `new`. Но можно объявить переменную абстрактного типа и присвоить ей объект наследника.
- Абстрактный класс может содержать и обычные методы с реализацией, поля и конструкторы.

```java
abstract class A
{
    abstract void method();          // абстрактный метод, без тела

    void print()                     // обычный метод
    {
        System.out.println("inside A method print");
    }
}

class B extends A
{
    void method()                    // реализация абстрактного метода
    {
        System.out.println("inside B method");
    }
}

class Main
{
    public static void main(String[] args)
    {
        // ОШИБКА: нельзя создать объект абстрактного класса
        // A x = new A();
        A a = new B();
        a.print();                   // inside A method print
        a.method();                  // inside B method
    }
}
```

### Пример: фигуры

Абстрактный класс `Figure` даёт возможность вычислять периметр и площадь фигуры, но сами формулы задаются в наследниках.

```java
abstract class Figure
{
    int[] a;                         // стороны (или радиус)

    Figure(int[] a)
    {
        this.a = a;
    }

    abstract double p();             // периметр
    abstract double s();             // площадь

    void print()
    {
        System.out.println("Фигура со сторонами:");
        for (int i = 0; i < a.length; i++)
            System.out.print(a[i] + " ");
        System.out.println();
    }
}

class Circle extends Figure
{
    Circle(int[] a) { super(a); }

    double p() { return 2 * Math.PI * a[0]; }
    double s() { return Math.PI * a[0] * a[0]; }
}

class Triangle extends Figure
{
    Triangle(int[] a) { super(a); }

    double p() { return a[0] + a[1] + a[2]; }

    double s()                       // формула Герона
    {
        double p2 = p() / 2;
        return Math.sqrt(p2 * (p2 - a[0]) * (p2 - a[1]) * (p2 - a[2]));
    }
}
```

В массиве типа `Figure` одновременно хранятся окружности и треугольники. Полиморфизм проявляется в том, что все объекты обрабатываются одним циклом с вызовом одних и тех же методов, а Java-машина каждый раз вызывает нужную версию метода в зависимости от конкретного объекта.

```java
import java.util.Scanner;

class Main
{
    public static void main(String[] args)
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Кол-во фигур");
        int n = sc.nextInt();

        Figure[] f = new Figure[n];

        for (int i = 0; i < n; i++)
        {
            System.out.println("1 - круг, 2 - треугольник");
            int p = sc.nextInt();

            if (p == 1)
            {
                System.out.println("Введи радиус");
                int[] a = new int[1];
                a[0] = sc.nextInt();
                f[i] = new Circle(a);
            }
            if (p == 2)
            {
                System.out.println("Введи 3 стороны");
                int[] a = new int[3];
                for (int j = 0; j < 3; j++)
                    a[j] = sc.nextInt();
                f[i] = new Triangle(a);
            }
        }

        for (int i = 0; i < n; i++)
        {
            f[i].print();
            System.out.println("P = " + f[i].p());
            System.out.println("S = " + f[i].s());
        }
    }
}
```

## Вопрос № 9. «Не статические внутренние классы»

**Ответ.**

В Java классы могут объявляться внутри других классов. Все вложенные классы делятся на два основных типа: **нестатические (внутренние)** и **статические**.

**Нестатический внутренний класс** объявлен внутри другого класса **без модификатора `static`**.

- Каждый экземпляр внутреннего класса неявно привязан к экземпляру внешнего класса и хранит ссылку на него.
- Благодаря этому внутренний класс имеет доступ ко **всем** элементам внешнего класса, даже объявленным как `private`.
- Создать объект внутреннего класса можно только через экземпляр внешнего класса: `outer.new InnerClass()`.

```java
public class OuterClass
{
    private String outerField = "Внешнее поле";

    // Нестатический внутренний класс
    class InnerClass
    {
        private String innerField = "Внутреннее поле";

        public void display()
        {
            // доступ к private-полю внешнего класса
            System.out.println(outerField);
            System.out.println(innerField);
        }
    }

    public void createInner()
    {
        // внутри внешнего класса — просто new
        InnerClass inner = new InnerClass();
        inner.display();
    }
}

public class Main
{
    public static void main(String[] args)
    {
        OuterClass outer = new OuterClass();
        // создание через экземпляр внешнего класса
        OuterClass.InnerClass inner = outer.new InnerClass();
        inner.display();
    }
}
```

### Когда используют внутренние классы

1. Когда сущность, описанная внутренним классом, не имеет самостоятельного смысла без сущности внешнего класса.
2. Когда нужно скрыть вспомогательную реализацию от остальной программы (внутренний класс видит внешний класс и его поля, а сам скрыт за ним).
3. Когда нужен удобный доступ к приватным полям внешнего объекта.
4. Когда требуется создать небольшую локальную реализацию некоторого класса.

## Вопрос № 10. «Статические внутренние классы»

**Ответ.**

**Статический вложенный класс** — класс, объявленный внутри другого класса **с модификатором `static`**.

- Он **не хранит ссылку** на объект внешнего класса.
- Имеет доступ **только к статическим полям** внешнего класса (к полям экземпляра — нет).
- Внутри него могут быть как статические, так и обычные методы.
- **Основное отличие от нестатического:** экземпляр статического вложенного класса можно создать **без экземпляра внешнего класса**.
- Используется для вспомогательных классов, логически связанных с внешним.

```java
public class OuterClass
{
    private static String staticField = "Статическое поле";
    private String instanceField = "Поле экземпляра";

    // Статический вложенный класс
    static class StaticNestedClass
    {
        public void display()
        {
            // доступ только к статическим полям
            System.out.println(staticField);
            // ОШИБКА: нет доступа к полям экземпляра
            // System.out.println(instanceField);
        }

        public static void staticMethod()
        {
            System.out.println("Статический метод вложенного класса");
        }
    }
}

public class Main
{
    public static void main(String[] args)
    {
        // создание без экземпляра внешнего класса
        OuterClass.StaticNestedClass nested =
                new OuterClass.StaticNestedClass();
        nested.display();

        OuterClass.StaticNestedClass.staticMethod();
    }
}
```

| | Нестатический (внутренний) | Статический вложенный |
|---|---|---|
| Ссылка на внешний объект | есть | нет |
| Доступ к полям внешнего класса | ко всем, включая `private` | только к статическим |
| Создание | `outer.new Inner()` | `new Outer.Nested()` |

## Вопрос № 11. «Локальные и анонимные вложенные классы»

**Ответ.**

### Локальный класс

**Локальный класс** — класс, объявленный **внутри некоторого метода**.

- Доступен только в пределах того метода, где объявлен.
- Имеет доступ к полям внешнего класса.
- Может обращаться к локальным переменным метода, если они `final` (или фактически не изменяются после инициализации).
- Если локальный класс объявлен в статическом методе, у него нет доступа к нестатическим полям внешнего класса.

```java
public class OuterClass
{
    private String outerField = "Внешнее поле";

    public void methodWithLocalClass()
    {
        String localVariable = "Локальная переменная";

        // Локальный класс внутри метода
        class LocalClass
        {
            public void display()
            {
                // поле внешнего класса
                System.out.println(outerField);
                // локальная переменная метода
                System.out.println(localVariable);
            }
        }

        LocalClass local = new LocalClass();
        local.display();
    }

    public static void staticMethodWithLocalClass()
    {
        class LocalClassInStatic
        {
            public void display()
            {
                // ОШИБКА: метод статический
                // System.out.println(outerField);
            }
        }
    }
}
```

### Анонимный класс

**Анонимный класс** — класс **без имени**, который объявляется и создаётся непосредственно в некотором выражении. Его применяют, когда нужно **однократно** переопределить поведение некоторого класса.

Синтаксис: после `new <Класс>(<аргументы конструктора>)` сразу пишется тело класса в фигурных скобках, а в конце ставится `;`.

```java
class Vehicle
{
    protected String type;
    protected int speed;

    public Vehicle(String type, int speed)
    {
        this.type = type;
        this.speed = speed;
    }

    public void move()
    {
        System.out.println(type + " движется со скоростью "
                           + speed + " км/ч");
    }
}

public class Main
{
    public static void main(String[] args)
    {
        // Анонимный класс-наследник Vehicle с доп. функциональностью
        Vehicle car = new Vehicle("Автомобиль", 60)
        {
            private int fuelLevel = 100;
            private boolean engineStarted = false;

            @Override
            // переопределяем метод move
            public void move()
            {
                if (!engineStarted)
                {
                    System.out.println("Заведите двигатель сначала!");
                    return;
                }
                super.move();
                fuelLevel -= 10;
                System.out.println("Остаток топлива: " + fuelLevel + "%");
            }

            public void startEngine()           // новый метод
            {
                engineStarted = true;
                System.out.println("Двигатель запущен");
            }
        };

        car.move();          // Заведите двигатель сначала!
        // ОШИБКА: у переменной типа Vehicle нет такого метода
        // car.startEngine();
    }
}
```

Новые методы, добавленные в анонимный класс, можно использовать только внутри самого анонимного класса, так как снаружи объект доступен через переменную родительского типа (`Vehicle`), а у этого типа таких методов нет.

## Вопрос № 12. «Интерфейсы»

**Ответ.**

**Интерфейс** в Java не является классом. В интерфейсе определяется **состав требований**, которые должны быть реализованы, но не определяется, **как** они должны быть реализованы. Каждый класс может по-своему реализовать требования интерфейса.

- Класс может реализовать **любое количество интерфейсов** (ключевое слово `implements`). Поэтому интерфейсы являются аналогом множественного наследования в C++.
- Все **переменные** интерфейса неявно считаются **константами**, поэтому им обязательно присваиваются значения. Классы, реализующие интерфейс, имеют к ним доступ.
- Все **методы** интерфейса неявно считаются **`public`**. Поэтому в классе при реализации метода обязательно явно писать `public`; в остальном заголовки методов в классе и интерфейсе должны полностью совпадать.

Структура объявления:

```
interface <Имя_интерфейса>
{
    <тип_результата> <имя_метода1>(<список параметров>);
    ...
    final <тип> <ИМЯ_КОНСТАНТЫ> = <значение>;   // final можно не писать
}

class <Имя_класса> [extends <суперкласс>]
                   [implements <интерфейс1>, <интерфейс2>, ...]
{
    // тело класса
}
```

### Реализация интерфейса

```java
interface Hello
{
    void meth1();
    void meth2();
}

class MyClass implements Hello
{
    public void meth1() { System.out.println("I am meth1"); }
    public void meth2() { System.out.println("I am meth2"); }

    void anotherMeth()  { System.out.println("I am not interface meth"); }
}
```

### Интерфейсная переменная

Можно объявить переменную интерфейсного типа и присвоить ей объект любого класса, реализующего этот интерфейс. Через неё можно вызывать только методы, объявленные в интерфейсе.

```java
class Test
{
    public static void main(String[] args)
    {
        Hello h = new MyClass();
        h.meth1();             // можно
        // h.anotherMeth();    // НЕЛЬЗЯ: метода нет в интерфейсе
    }
}
```

### Наследование интерфейсов

Интерфейсы имеют собственную иерархию наследования, которая не пересекается с иерархией классов. Если класс реализует интерфейс-наследник, он должен реализовать методы и самого интерфейса, и его родителя.

```java
interface A
{
    void meth1();
    void meth2();
}

interface B extends A
{
    void meth3();
}

class C implements B
{
    public void meth1() { System.out.println("Meth1"); }
    public void meth2() { System.out.println("Meth2"); }
    public void meth3() { System.out.println("Meth3"); }
}
```

### Методы по умолчанию

В последних версиях языка в интерфейсе можно объявлять **методы по умолчанию** (ключевое слово `default`). Они имеют реализацию, которая используется, если класс не реализовал этот метод. Класс может и заместить метод по умолчанию.

```java
interface Hello
{
    default void meth1()
    {
        System.out.println("In interface meth1");
    }
    void meth2();
}

class Class1 implements Hello
{
    // замещает default
    public void meth1() { System.out.println("I am meth1"); }
    public void meth2() { System.out.println("I am meth2"); }
}

class Class2 implements Hello
{
    // meth1 не реализован
    public void meth2() { System.out.println("I am meth2"); }
}

class Test
{
    public static void main(String[] args)
    {
        Hello h = new Class2();
        h.meth1();            // In interface meth1
        h = new Class1();
        h.meth1();            // I am meth1
    }
}
```

## Вопрос № 13. «Исключения. try, catch, finally (что это такое)»

**Ответ.**

### Что такое исключение

**Исключения** — внештатные ситуации, которые могут возникнуть во время выполнения программы.

В Java исключение — это **объект**, который описывает некоторую ошибочную ситуацию. Когда она возникает, создаётся объект-исключение и **выбрасывается** в метод, вызвавший ошибку. Метод может либо сам обработать исключение, либо передать его дальше. В любом случае выброшенное исключение будет захвачено и обработано.

Исключения могут генерироваться:

- **автоматически** исполняющей системой Java — обычно это фундаментальные ошибки и ограничения языка (деление на 0, выход за границы массива);
- **вручную** программистом — обычно это аварийные ситуации конкретной программы (см. вопрос 14).

### Иерархия исключений

```
Object
  └── Throwable
        ├── Exception   — могут быть обработаны программистом
        └── Error       — генерируются и отлавливаются системой Java
```

### Конструкция try – catch – finally

```
try
{
    // операторы, в которых может возникнуть ошибка
}
catch (ExceptionType1 exOb)
{
    // обработка исключения типа ExceptionType1
}
catch (ExceptionType2 exOb)
{
    // обработка исключения типа ExceptionType2
}
finally
{
    // операторы, которые выполняются всегда
}
```

- **`try`** — блок, в который помещаются операторы, способные привести к ошибке. Если ошибка случается, создаётся объект-исключение и выбрасывается этим блоком.
- **`catch`** — блок, который захватывает исключение и обрабатывает его. Блоков `catch` может быть несколько, так как каждый отлавливает только свой тип исключения.
- **`finally`** — блок с кодом, который должен выполниться **независимо от того**, было выброшено исключение или нет.

### Необработанное исключение

```java
Random r = new Random();
int a = r.nextInt(10);
int b = r.nextInt(10);
int c = b / a;              // если a == 0 — ошибка деления на 0
```

Если обработчика нет, исключение захватывается **обработчиком по умолчанию**: он печатает строку с описанием исключения (например, `java.lang.ArithmeticException: / by zero`) и **завершает программу**.

### Перехват исключения

```java
import java.util.Random;

class Test
{
    public static void main(String[] args)
    {
        Random r = new Random();
        int a = r.nextInt(10);
        int b = r.nextInt(10);
        try
        {
            int c = b / a;
            System.out.println("c = " + c);
        }
        catch (ArithmeticException e)
        {
            System.out.println("Ошибка деления на 0");
        }
        finally
        {
            System.out.println("Этот блок выполняется всегда");
        }
    }
}
```

Если `try`–`catch` стоит внутри цикла, то при ошибке программа не завершается, а продолжает работу:

```java
Random r = new Random();
for (int i = 0; i < 10000; i++)
{
    int a, b, c;
    try
    {
        a = r.nextInt(10);
        b = r.nextInt(10);
        c = 1234 / a / b;
    }
    catch (ArithmeticException e)
    {
        c = 0;
    }
    System.out.println(c);
}
```

### Множественный catch

Если один участок кода может выбросить исключения разных типов, используется несколько блоков `catch`, каждый для своего типа.

```java
int[] m = new int[3];
Random r = new Random();
int a = r.nextInt(10);
int b = r.nextInt(10);
try
{
    int c = 1234 / a / b;
    m[45] = c;
}
catch (ArrayIndexOutOfBoundsException e)
{
    System.out.println("Выход за границы индекса");
}
catch (ArithmeticException e)
{
    System.out.println("Деление на 0");
}
```

**Порядок выполнения.** После выброса исключения блоки `catch` просматриваются сверху вниз, выполняется **первый** подходящий по типу блок, остальные пропускаются.

**Порядок записи.** Подклассы исключений должны располагаться **до** своих суперклассов. Иначе `catch` с суперклассом перехватит и все исключения подклассов, а `catch` с подклассом станет **недостижимым кодом**. Недостижимый код в Java — ошибка, обнаруживаемая ещё на этапе сборки.

```java
try { ... }
catch (Exception e)
{
    System.out.println("Перехват классом Exception");
}
catch (ArithmeticException e)   // ОШИБКА компиляции: недостижимый код
{
    System.out.println("Недостижимый код");
}
```

## Вопрос № 14. «Исключения. throw и throws»

**Ответ.**

### Оператор throw

Помимо исключений, которые выбрасывает исполняющая система Java автоматически, программист может **выбросить исключение вручную** с помощью оператора **`throw`**.

После `throw` выполнение программы приостанавливается и просматривается ближайший блок `try` в поисках подходящего по типу блока `catch`:

1. если соответствие найдено — выполняется этот `catch`;
2. если нет — просматривается следующий (внешний) блок `try` и так далее;
3. если соответствие не найдено ни в одном `try`, исключение захватывается обработчиком по умолчанию.

```java
try
{
    Scanner in = new Scanner(System.in);
    int x = in.nextInt();
    if (x >= 30)
        throw new Exception("Число x должно быть меньше 30");
}
catch (Exception e)
{
    System.out.println(e.getMessage());
}
System.out.println("Программа завершена");
```

### Конструкторы исключений и getMessage()

Все встроенные классы исключений имеют **два конструктора**:

- без параметров;
- с параметром типа `String` — строкой, описывающей исключение.

Эту строку можно получить методом **`getMessage()`** класса `Exception`.

### Ключевое слово throws

Если метод может выбрасывать исключения, которые **сам не обрабатывает**, он должен оповестить об этом другие методы, чтобы они могли обезопасить свою работу. Для этого в заголовке метода пишется **`throws`** и перечисляются все типы исключений, которые метод может выбросить. Если метод выбрасывает исключение, но не оповещает об этом, будет ошибка времени сборки программы.

*Уточнение:* это правило обязательно для проверяемых исключений (`Exception` и его наследники, кроме `RuntimeException`). Для наследников `RuntimeException` (например, `ArithmeticException`, `ArrayIndexOutOfBoundsException`) указывать `throws` не обязательно.

```java
public class Main
{
    public static int getFactorial(int num) throws Exception
    {
        if (num < 1)
            throw new Exception("Число не может быть меньше 1");

        int result = 1;
        for (int i = 1; i <= num; i++)
            result *= i;
        return result;
    }

    public static void main(String[] args)
    {
        try
        {
            int result = getFactorial(-6);
            System.out.println(result);
        }
        catch (Exception e)
        {
            // Число не может быть меньше 1
            System.out.println(e.getMessage());
        }
    }
}
```

| | `throw` | `throws` |
|---|---|---|
| Где пишется | в теле метода | в заголовке метода |
| Что делает | выбрасывает конкретный объект-исключение | объявляет, какие исключения метод может выбросить |
| После него | объект: `throw new Exception("...")` | типы: `throws Exception, ...` |

## Вопрос № 15. «Пользовательские классы исключений»

**Ответ.**

Пользователь может создавать **собственные классы исключений**. Они должны **наследоваться от класса `Exception`**.

Собственные классы исключений позволяют писать блоки `catch`, которые отлавливают и обрабатывают именно пользовательские исключения, не путая их с общими типами исключений. В свой класс можно добавить дополнительные поля и методы (например, значение, вызвавшее ошибку).

Сообщение об ошибке передаётся в конструктор `Exception` через `super(message)`, после чего его можно получить методом `getMessage()`.

```java
class FactorialException extends Exception
{
    // значение, вызвавшее ошибку
    private int number;

    public int getNumber() { return number; }

    public FactorialException(String message, int num)
    {
        // сообщение для getMessage()
        super(message);
        number = num;
    }
}

class Factorial
{
    public static int getFactorial(int num) throws FactorialException
    {
        if (num < 1)
            throw new FactorialException(
                    "Число не может быть меньше 1", num);

        int result = 1;
        for (int i = 1; i <= num; i++)
            result *= i;
        return result;
    }
}

public class Main
{
    public static void main(String[] args)
    {
        try
        {
            int result = Factorial.getFactorial(-6);
            System.out.println(result);
        }
        catch (FactorialException ex)
        {
            // Число не может быть меньше 1
            System.out.println(ex.getMessage());
            System.out.println(ex.getNumber());    // -6
        }
    }
}
```

Порядок работы с пользовательским исключением:

1. Объявить класс-наследник `Exception` (конструктор вызывает `super(message)`).
2. В методе, где возможна ошибка, выбросить его через `throw new ...` и указать в заголовке `throws ...`.
3. В вызывающем коде перехватить его в `try`–`catch` по своему типу.

## Памятка к задаче — работа с классом в main

В задаче нужно описать класс и в `main` базово показать работу с ним: создать объекты через `new`, вызвать конструкторы и методы, вывести результат. Типовой шаблон по материалам лекций:

```java
class Student
{
    // поля закрыты (инкапсуляция)
    private String name;
    private int[] marks;

    public Student(String name, int[] marks)  // конструктор
    {
        this.name = name;
        this.marks = marks;
    }

    public String getName() { return name; }  // метод доступа

    public double average()                   // метод обработки данных
    {
        int sum = 0;
        for (int i = 0; i < marks.length; i++)
            sum += marks[i];
        return (double) sum / marks.length;
    }

    public void print()
    {
        System.out.println(name + ": средний балл = " + average());
    }
}

public class Main
{
    public static void main(String[] args)
    {
        // 1. Создание объектов
        Student s1 = new Student("Иван", new int[] {5, 4, 5});
        Student s2 = new Student("Анна", new int[] {3, 4, 4});

        // 2. Вызов методов
        s1.print();
        s2.print();

        // 3. Массив объектов и обработка в цикле
        Student[] group = {s1, s2};
        Student best = group[0];
        for (int i = 1; i < group.length; i++)
            if (group[i].average() > best.average())
                best = group[i];
        System.out.println("Лучший студент: " + best.getName());
    }
}
```
