## 1. Официальные контрольные вопросы и ответы

### Лабораторная работа №1. Знакомство с Astra Linux SE и графической оболочкой Fly

1. **Сколько минимально места на диске требуется ОС Astra Linux SE при установке с графической оболочкой Fly и ПО, входящим в состав дистрибутива?**
    
      
    - Для установки ОС с графическим интерфейсом и ПО требуется не менее **20 ГБ** свободного места на виртуальном диске.
        
          
        
2. **В какую группу, дающую право выполнять команды от имени суперпользователя root, будет включена учетная запись администратора, созданная в процессе установки ОС?**
    
      
    - В группу **`sudo`** (а также в специфичную для Astra Linux группу **`astra-admin`**).
        
          
        
3. **Какой вариант разметки диска был выбран при демонстрации процесса установки ОС?**
    
      
    - Метод разметки «Авто — использовать весь диск» и схема «Все файлы в одном разделе (рекомендуется новичкам)».
        
          
        
4. **Что такое GRUB?**
    
      
    - **GRUB** (_GRand Unified Bootloader_) — универсальный системный загрузчик операционной системы, устанавливаемый в главную загрузочную запись (MBR) и отвечающий за инициализацию ядра Linux.
        
          
        
5. **Какое приложение отвечает за работу рабочего стола?**
    
      
    - За организацию работы рабочего стола и графической среды отвечает оконный менеджер **`fly-wm`**.
        
          
        

### Лабораторная работа №2. Работа с терминалом и оболочкой Bash

1. **Как называется устройство, которое может отправлять команды ЭВМ и выводит на экран полученный результат?**
    
      
    - Терминал (эмулятор терминала или псевдотерминал).
        
          
        
2. **Какая папка отвечает за конфигурационные файлы?**
    
      
    - Системный каталог **/etc**.
        
          
        
3. **Какая управляющая последовательность завершает операцию?**
    
      
    - Сочетание клавиш **`Ctrl + C`** (отправляет сигнал прерывания `SIGINT`).
        
          
        
4. **Какая команда выводит список файлов и каталогов текущей директории?**
    
      
    - Команда **`ls`**.
        
          
        
5. **Какими текстовыми редакторами можно редактировать файл?**
    
      
    - Консольными редакторами **`nano`**, **`vi`**, **`vim`**, **`mcedit`**.
        
          
        
6. **Какой командой можно получить справку на любую команду?**
    
      
    - Командой **`man <имя_команды>`**, встроенной командой **`help`** или флагом **`--help`**.
        
          
        
7. **Какой командой можно перенаправить стандартный вывод в файл hosts.bak?**
    
      
    - Оператором перенаправления: **`команда > hosts.bak`** (или **`>>`** для дозаписи).
        
          
        
8. **В какой переменной хранится список каталогов для запуска исполняемых файлов?**
    
      
    - В переменной окружения **`$PATH`**.
        
          
        
9. **Какой поток данных передается по конвейеру?**
    
      
    - Стандартный вывод (`STDOUT`, дескриптор `1`) левой команды передается на стандартный ввод (`STDIN`, дескриптор `0`) правой команды.
        
          
        
10. **Какая команда отображает историю команд?**
    
      
    - Команда **`history`**.
        
          
        
11. **Какой файл содержит профиль текущего пользователя?**
    
      
    - Настройки интерактивной сессии хранятся в **`~/.bashrc`**, а профиль входа — в **`~/.profile`** или **`~/.bash_profile`**.
        
          
        

### Лабораторная работа №3. Работа с файлами и каталогами. FHS

1. **Какой каталог содержит конфигурационные файлы?**
    
      
    - Каталог **/etc**.
        
          
        
2. **Можно ли в ОС Linux создать два файла `/tmp/test.txt` и `/tmp/TEST.txt`?**
    
      
    - Да, традиционные файловые системы Linux чувствительны к регистру символов.
        
          
        
3. **Какая максимальная длина имени файла в ОС Linux?**
    
      
    - Максимальная длина имени файла — **255 байт**, полного пути — **4096 байт**.
        
          
        
4. **Каким символом в выводе команды `ls -l` помечаются обычные файлы?**
    
      
    - Символом дефиса **`-`**.
        
          
        
5. **Можно ли найти неименованный канал в структуре каталогов?**
    
      
    - Нет, неименованный канал существует только в ОЗУ между связанными процессами.
        
          
        
6. **Каким ключом команды `ls` можно отобразить айноду?**
    
      
    - Ключом **`-i`** (например, `ls -i` или `ls -li`).
        
          
        
7. **Можно ли создать жесткую ссылку на файл, расположенный на другой файловой системе?**
    
      
    - Нет, жесткая ссылка привязана к номеру inode, а номера inode уникальны только в рамках одной файловой системы.
        
          
        
8. **Путь `tmp/1/2.txt` является абсолютным или относительным?**
    
      
    - Относительным, так как не начинается с корневого каталога `/`.
        
          
        
9. **Что будет при вызове команды `touch` с существующим файлом?**
    
      
    - Обновятся временные метки доступа и модификации файла без изменения содержимого.
        
          
        

## 2. Справочник команд из отчетов

### 📌 Лабораторная работа №1

- `passwd` — изменение пароля текущей учетной записи (`sa`). Запрашивает текущий пароль, затем новый пароль дважды.
    
      
    

### 📌 Лабораторная работа №2

- `tty` — вывод имени файла псевдотерминала текущей сессии (например, `/dev/pts/0`).
    
      
    
- `echo "Привет!" > /dev/pts/0` — отправка сообщения в указанный псевдотерминал через перенаправление вывода (`>`).
    
      
    
- `echo "Ширина:$COLUMNS, Высота:$LINES"` — вывод размеров окна терминала в столбцах и строках из системных переменных.
    
      
    
- `sleep 9000` — приостановка работы терминала на 9000 секунд (для демонстрации `Ctrl + C`).
    
      
    
- `mc` — запуск файлового менеджера Midnight Commander (выход по клавише `F10`).
    
      
    
- `pwd` — вывод абсолютного пути к текущему рабочему каталогу (_Print Working Directory_).
    
      
    
- `cd /etc` — переход в системный каталог конфигурационных файлов `/etc`.
    
      
    
- `ls` — просмотр списка файлов и папок в текущей директории.
    
      
    
- `cat hostname` — чтение и вывод содержимого файла `hostname` в поток `STDOUT`.
    
      
    
- `cat hostname > ~/hostname.old` — создание резервной копии файла `hostname` в домашнем каталоге (`~`).
    
      
    
- `nano /etc/hostname` — запуск текстового редактора Nano (без `sudo` выводит предупреждение о неразрешенной записи).
    
      
    
- `sudo !!` — повторный запуск предыдущей команды (`!!`) с правами суперпользователя (`sudo`).
    
      
    
- `echo "Привет, $USER"` — вывод приветствия с подстановкой имени текущего пользователя.
    
      
    
- `env` — просмотр списка всех глобальных (экспортированных) переменных окружения.
    
      
    
- `set` — просмотр всех переменных (включая локальные) и функций текущей оболочки.
    
      
    
- `set | grep -E 'LINES|COLUMNS'` — фильтрация переменных вывода с использованием конвейера (`|`) и регулярных выражений (`grep -E`).
    
      
    
- `reboot` — попытка перезагрузки от обычного пользователя (возвращает ошибку «команда не найдена»).
    
      
    
- `echo $PATH` — вывод списка директорий, в которых оболочка ищет исполняемые файлы команд.
    
      
    

### 📌 Лабораторная работа №3

- `find /usr/share -type f -size +500k` — поиск обычных файлов (`-type f`) размером строго более 500 Кб в каталоге `/usr/share`.
    
      
    
- `find /usr/share -type f -size +500k > /tmp/search.list` — поиск файлов с сохранением результата в файл `/tmp/search.list`.
    
      
    
- `du -k /tmp/search.list > /tmp/search-size.txt` — определение размера файла в килобайтах (`-k`) и перенаправление записи.
    
      
    
- `wc -l /tmp/search.list >> /tmp/search-size.txt` — подсчет строк (`-l`) и дозапись результата в конец файла (`>>`).
    
      
    
- `mkdir -p /tmp/block6/task/1/2/3` — создание всей цепочки вложенных каталогов за одну команду (`-p`).
    
      
    
- `mv /tmp/search.list /tmp/search-size.txt /tmp/block6/task/1/2/3/` — перемещение нескольких файлов в директорию.
    
      
    
- `ln search-size.txt hardlink_size` — создание жесткой ссылки, указывающей на тот же номер inode.
    
      
    
- `ln -s search-size.txt symlink_size` — создание символической ссылки (`-s`), хранящей путь к файлу.
    
      
    
- `ls -li` — просмотр содержимого каталога с отображением номеров inode (`-i`).
    
      
    
- `rm -rf /tmp/block6` — принудительное (`-f`) рекурсивное (`-r`) удаление каталога со всеми вложенными объектами.
    
      
    
- `touch file.txt` — создание пустого файла или обновление временных меток.
    
      
    
- `realpath file.txt` — получение абсолютного полного пути к файлу.
    
      
    
- `file logo.png` — определение истинного типа файла по его сигнатуре.
    
      
    
- `stat file.txt` — получение подробной информации из inode (права, размеры, блоки, ссылки, метки).
    
      
    

## 3. Дополнительные теоретические вопросы от преподавателя

### ❓ По Лабораторной работе №1 (Astra Linux SE & Fly)

> [!question] Какие уровни защищенности существуют в Astra Linux Special Edition? В системе предусмотрено 3 уровня защищенности:
> 
>   
> 
> - **«Орел»** — базовый уровень;
>     
>       
>     
> - **«Воронеж»** — усиленный уровень (мандатный контроль целостности, замкнутая программная среда, очистка памяти);
>     
>       
>     
> - **«Смоленск»** — максимальный уровень (дополнительно содержит мандатное управление доступом МУД/MAC).
>     
>       
>     

> [!question] В чем разница между «Десктопной» и «Планшетной» сессиями рабочего стола Fly?
> 
>   
> 
> - **Десктопная:** оптимизирована для работы с мышью и клавиатурой, приложения открываются в масштабируемых окнах.
>     
>       
>     
> - **Планшетная:** оптимизирована для сенсорных экранов, приложения запускаются на весь экран без оконных заголовков.
>     
>       
>     

> [!question] Как переключиться из графического режима в консольный (текстовый) и обратно?
> 
>   
> 
> - Переход в текстовые виртуальные консоли tty1–tty6: комбинация **`Ctrl + Alt + F1`** ... **`F6`**.
>     
>       
>     
> - Возврат в графическую сессию (Fly): комбинация **`Ctrl + Alt + F7`**.
>     
>       
>     

> [!question] Как просмотреть скрытые файлы в графическом файловом менеджере и в консоли?
> 
>   
> 
> - В графическом менеджере — через меню «Настройки вида».
>     
>       
>     
> - В консоли — выполнением команды **`ls -a`** (отображает все файлы, в том числе начинающиеся с точки `.`).
>     
>       
>     

### ❓ По Лабораторной работе №2 (Терминал, Shell, процессы, потоки)

> [!question] В чем разница между виртуальной консолью (`/dev/ttyN`) и псевдотерминалом (`/dev/pts/N`)?
> 
>   
> 
> - **Виртуальная консоль (TTY):** системный текстовый терминал, реализуемый напрямую ядром ОС (tty1–tty6).
>     
>       
>     
> - **Псевдотерминал (PTS):** программное устройство, эмулирующее терминал в графической среде (`fly-term`, `xterm`, `ssh`).
>     
>       
>     

> [!question] В чем разница между комбинациями `Ctrl + C` и `Ctrl + Z`?
> 
>   
> 
> - **`Ctrl + C`:** отправляет сигнал `SIGINT` и **полностью завершает/убивает** процесс.
>     
>       
>     
> - **`Ctrl + Z`:** отправляет сигнал `SIGTSTP` и **приостанавливает** процесс, переводя его в фоновый режим (возврат в интерактивный режим — команда **`fg`**).
>     
>       
>     

> [!question] Чем отличаются операторы объединения команд `;`, `&&` и `||`?
> 
>   
> 
> - **`;`** (последовательно) — команды выполняются друг за другом независимо от результата.
>     
>       
>     
> - **`&&`** (логическое И) — следующая команда выполнится **только при успешном** завершении предыдущей (код 0).
>     
>       
>     
> - **`||`** (логическое ИЛИ) — следующая команда выполнится **только при ошибке** в предыдущей.
>     
>       
>     

> [!question] Назовите 3 стандартных потока ввода-вывода и их числовые дескрипторы.
> 
>   
> 
> 1. **`0` — STDIN** (_standard input_) — стандартный поток ввода (по умолчанию клавиатура).
>     
>       
>     
> 2. **`1` — STDOUT** (_standard output_) — стандартный поток вывода (по умолчанию экран).
>     
>       
>     
> 3. **`2` — STDERR** (_standard error_) — стандартный поток ошибок (по умолчанию экран).
>     
>       
>     

> [!question] В чем различие между командами `env` и `set`?
> 
>   
> 
> - **`env`** выводит только глобальные (экспортированные в окружение) переменные.
>     
>       
>     
> - **`set`** выводит абсолютно все переменные (включая локальные переменные Bash) и пользовательские функции.
>     
>       
>     

> [!question] Чем отличается командная оболочка Bash от Dash?
> 
>   
> 
> - **Bash** (`/bin/bash`) — интерактивная оболочка с поддержкой автодополнения, истории и расширенного синтаксиса.
>     
>       
>     
> - **Dash** (`/bin/dash`) — компактная и быстродействующая POSIX-совместимая оболочка малого объема для системных скриптов.
>     
>       
>     

### ❓ По Лабораторной работе №3 (Файловая система, Inode, FHS, ссылки)

> [!question] В чем ключевое отличие концепций «Всё есть файл» (Linux) и «Всё есть объект» (Windows)? В Linux доступ к аппаратному обеспечению, процессам, виртуальным терминалам и межпроцессным каналам осуществляется через единый файловый интерфейс в едином дереве каталогов начиная с корня `/`. В Windows ресурсы представляют собой объекты с методами и свойствами, а дисковые накопители изолированы буквами разделов (`C:`, `D:`).
> 
>   

> [!question] Что такое Inode (индексный дескриптор) и хранится ли в нем имя файла? Inode — структура данных фиксированного размера (обычно 256 байт), хранящая метаинформацию о файле: размер, права доступа (`rwx`), UID/GID владельцев, даты изменения и адреса блоков данных. **Имя файла в inode не хранится** — оно содержится в файле каталога.
> 
>   

> [!question] В чем различие между жесткой и символической ссылкой?
> 
>   
> 
> - **Жесткая ссылка:** еще одно имя для той же айноды. Имеет тот же номер inode. Нельзя создавать на каталоги и на файлы других файловых систем.
>     
>       
>     
> - **Символическая ссылка:** отдельный файл со своим номером inode, содержащий текстовый путь к целевому файлу. Может ссылаться на папки и файлы других дисков.
>     
>       
>     

> [!question] Что произойдет с файлом на диске, если у него 2 жесткие ссылки и одну из них удалили командой `rm`? Файл останется на диске. Команда `rm` удалит запись из каталога и уменьшит счетчик жестких ссылок в inode с 2 до 1. Файл физически удалится с диска только тогда, когда счетчик ссылок станет равен 0.
> 
>   

> [!question] Каково назначение основных каталогов стандарта FHS?
> 
>   
> 
> - **/etc** — конфигурационные файлы системы и сервисов.
>     
>       
>     
> - **/tmp** — временные файлы (очищается при перезагрузке).
>     
>       
>     
> - **/var** — динамически изменяемые файлы (логи, кэш, почта).
>     
>       
>     
> - **/dev** — файлы устройств (диски, терминалы, мышь).
>     
>       
>     
> - **/proc** и **/sys** — виртуальные файловые системы информации о ядре и процессах.
>     
>       
>     
> - **/boot** — файлы загрузчика GRUB и ядра Linux.
>     
>       
>     
> - **/usr** — прикладные пользовательские программы и библиотеки.
>
