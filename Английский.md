Вот теория с добавлением строгих определений для каждого типа рядов.

---

1. Знакоположительные ряды

Определение: Числовой ряд \sum_{n=1}^{\infty} a_n называется знакоположительным, если все его члены неотрицательны, то есть a_n \ge 0 для любого n \in \mathbb{N}.

Свойства и признаки:

· Для знакоположительных рядов понятия «сходимость» и «абсолютная сходимость» совпадают. Условной сходимости здесь быть не может.
· Признак Д'Аламбера: Если \lim_{n \to \infty} \frac{a_{n+1}}{a_n} = D, то при D < 1 ряд сходится, при D > 1 — расходится. При D=1 признак не работает.
· Радикальный признак Коши: Если \lim_{n \to \infty} \sqrt[n]{a_n} = C, то при C < 1 ряд сходится, при C > 1 — расходится. При C=1 признак не работает.
· Предельный признак сравнения: Если a_n \sim b_n при n \to \infty (то есть \lim_{n \to \infty} \frac{a_n}{b_n} = k, где 0 < k < \infty), то ряды \sum a_n и \sum b_n сходятся или расходятся одновременно. В качестве эталона обычно берут обобщенный гармонический ряд \sum \frac{1}{n^p} (сходится при p > 1, расходится при p \le 1).

---

2. Знакочередующиеся ряды

Определение: Числовой ряд называется знакочередующимся, если его соседние члены имеют противоположные знаки. Его можно записать в виде:

\sum_{n=1}^{\infty} (-1)^{n-1} b_n = b_1 - b_2 + b_3 - b_4 + \dots 

где b_n > 0 для всех n.

Теорема Лейбница (достаточный признак сходимости):
Знакочередующийся ряд сходится, если одновременно выполняются два условия:

1. Члены ряда убывают по модулю монотонно: b_{n+1} \le b_n для всех n.
2. Предел общего члена равен нулю: \lim_{n \to \infty} b_n = 0.

Оценка остатка: Если ряд сходится по признаку Лейбница, то погрешность при замене его суммы на n-ю частичную сумму S_n не превышает модуля первого отброшенного члена: |S - S_n| \le b_{n+1}.

---

3. Знакопеременные ряды

Определение: Числовой ряд \sum_{n=1}^{\infty} a_n называется знакопеременным, если среди его членов есть как положительные, так и отрицательные числа (при этом они могут чередоваться в произвольном порядке, а не строго по очереди). Знакочередующиеся ряды — это частный случай знакопеременных.

Определения видов сходимости:

1. Абсолютная сходимость: Ряд \sum a_n называется абсолютно сходящимся, если сходится ряд, составленный из модулей его членов, то есть \sum |a_n|.
2. Условная сходимость: Ряд \sum a_n называется условно сходящимся, если сам он сходится, а ряд из его модулей \sum |a_n| расходится.

Теорема: Если ряд сходится абсолютно, то он сходится и в обычном смысле (перестановка членов абсолютно сходящегося ряда не меняет его суммы).

Алгоритм исследования знакопеременного ряда:

1. Составляем ряд из модулей \sum |a_n| и исследуем его как знакоположительный.
2. Если \sum |a_n| сходится \implies исходный ряд сходится абсолютно (исследование закончено).
3. Если \sum |a_n| расходится, то проверяем сам исходный ряд \sum a_n. Если он сходится (например, по признаку Лейбница) \implies сходимость условная. Если расходится — исходный ряд расходится.
